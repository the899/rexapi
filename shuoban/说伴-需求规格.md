## 1. 产品定位

说伴是给上海初一家长在家辅导英语口语的私人工具，不是应试机，也不是应用商店产品。

- 教材对齐：2024 沪教牛津 五四学制 七年级（上册 Starter + Units 1–6，下册 Units 1–6，共 13 单元）。
- 学校不考「说」。目标是敢开口、有兴趣，不是分数、不是背课文。
- 隐喻：一个会英语的家长坐在旁边。电脑演 A（先开口），学生当 B（接话）。带、判、教、回放。
- 不是测验，不是朗读机。台词是产品原创的校园短对话，对齐单元主题与课内词汇，不逐字抄课文（版权与产品都禁止原文照搬）。课文只可当创作模特。
- 交付（暂定）：轻量 PWA。HTTPS 链接打开即可；可加到主屏幕，全屏无地址栏。不是 IPA/APK，不是微信小程序。

## 2. 用户与场景

| 角色 | 做什么 | 不做什么 |
| --- | --- | --- |
| 学生（上海初一） | 选主题、演 B、被教、回放、随时重练 | 不填台词、对话中不看分数 |
| 家长 | 同一部手机右上角「布置」：勾主题、开口次数、目标档；当场能听见孩子说 | 不打字录入对话、不登录账号、不回放学生录音审音 |
| 产品 | 填内容表、导入主题 | 家长不参与写句 |

无登录。进度存在本机 `localStorage`。一家一机即可。

## 3. 版本范围

### 3.1 MVP（现行，已实现或按此实现）

- 单元：七年级上 Unit 1「尝试新事物」，4 个短主题，各最多 4 对 A-B。
- 学生四步：选课 → 开场 → 对话 → 回放。教叠在对话屏上，不是新页。
- 家长两屏布置。
- 运行时：云端 TTS 出声（预拉 + 本地缓存）+ 云端 ASR 转写后按关键词判内容。
- 静态单页，Cloudflare Pages。语音走自有域名上的 Worker。
- 轻量 PWA（待做）：manifest + 图标 + `display: standalone`。练习中不弹安装。无离线 Service Worker（语音必须在线）。

### 3.2 下一版（MVP 之后，已锁定、尚未做）

- 运行时不调用 TTS，只保留 ASR。
- 对话在 Excel 定稿后，用 CosyVoice 按表生成 mp3，存 Cloudflare R2。
- 客户端只播这些静态文件。TTS 只出现在题库生产，不出现在孩子手机上。
- 进度条预拉可取消或只给缺文件兜底。

全年 13 单元 × 每单元 4 主题是目录范围，内容按表逐单元录入，不堵在 MVP 里一次写完。

## 4. 信息架构

屏数按功能需要，不迷信「永远四屏」。学生练一个主题刚好四步所以是四屏；布置两屏；教是叠层；设置若再有也是另屏。

所有页面共用同一个 `#app` 画框，宽度一致。

```
选课 ──布置──► 布置 1（勾主题）──► 布置 2（开口次数 / 目标）
  │
  └──► 开场（你是 B）──► 对话（含教叠层）──► 回放
```

## 5. 学生路径

### 5.1 选课

- 展示当前单元短主题（MVP：Unit 1 四条）。
- 每条显示是否在任务中、已达档（会说 / 还生 / 再练 / 未练）。
- 右上角「布置」。顶栏目标文案：开口 N 次，练到 会说或还生。
- 未布置进任务的主题仍可自练。

### 5.2 开场

- 标明：说伴是 A（先说），你是 B（接话）。
- 点「开始」进入对话。
- MVP：进主题即预拉本主题要用的 A / B / 截1 / 截2。未齐时点「开始」出进度条，齐了再演。第二次进同一主题走本地缓存，可秒开。

### 5.3 对话（主屏不离开）

- 上：A 的句子（说伴说）。
- 中：B 的台词。默认全句；同一主题完整演完两次后改关键词，可随时点回全句，不扣档。
- 下：录音按钮。途中已改为 **点击说话 / 点击停止**（不再按住）。停止后按钮转圈、不可点，ASR 返回后才恢复。
- 进度：点点或句序，不显示分数。
- A 说完才轮到 B。过了或接近 → A 接下句。没对上 → 同屏进入教。

### 5.4 回放

- 时间轴 A1 B1 A2 B2…
- 只听说伴示范（A 与 B 的范读）；再练句置顶。
- 不保存、不回放学生开口录音。家长确认练过看勾和档（会说 / 还生 / 再练）。
- 演完给出主题三档（见第 9 节），不在对话中途弹分。

## 6. 家长布置

同一部手机，无登录。

1. 多选当前单元主题（默认全选）。
2. 开口次数 1–4，默认 2。目标档仅 还生 / 会说，默认 会说。再练是结果，不能当目标。

点「布置好了」回选课。已完成勾保留；改任务覆盖这一次布置，不抹掉历史最好档。

脚本按 4 对 A-B 撰写；运行时只演前 N 对（N = 开口次数）。1 是热身，4 给已经敢说的孩子。判定、教、回放规则不随 N 变。

## 7. 判定（只判内容，不打发音分）

录音：点击开始、再点停止。音频只用于当次 ASR，用完丢弃，不落盘、不上传、不进回放。太短 / 没声 / 纯噪音 → 「没听清，再说一次」，不进教、不记错。连续三次没听清：说伴把第一意群（截1）念出来领说。

听清后：ASR 文本对关键词（意思不能丢）。允许 I'm / I am、小停顿、句尾语气词。

| 单句 | 条件 | 接着做什么 |
| --- | --- | --- |
| 过了 | 关键词都在、意思完整 | A 接下句 |
| 接近 | 关键词过半，缺修饰或后半 | 仍接下句，记接近 |
| 没对上 | 关键词对不上或说成别的意思 | 进教 |

内容对、发音差 = 接近，不拦路。无百分制。

## 8. 教（叠在对话屏，不是新页）

没对上后停演、当老师。A 的原句保持可见。口诀：先示范，再拆，再合，再回到对话。不讲语法、不打分。

| 步 | 名 | 行为 |
| --- | --- | --- |
| 1 | 听我的 | 示范 B 的整句 |
| 2 | 跟两截 | 按意群跟读（截1，再截2） |
| 3 | 合成句 | 整句再跟 |
| 4 | 接着演 | 重放上一句 A，孩子对着 A 再说 B |

同一句最多两轮。仍不成：用说伴声音把 B 垫过去，对话继续，该句标再练。孩子可随时「先跳过教」。

教与对话共用同一套音量、语速，没有慢速另一套声。

## 9. 主题三档与任务勾

学生和家长看同一档，演完才给，对话中不弹。

| 档 | 含义 |
| --- | --- |
| 会说 | N 句都过了，全程没进过教 |
| 还生 | 演完，但有接近，或教过之后才过 |
| 再练 | 有句子被垫过去 |

未达家长目标：说伴说再来一次，主题不算完成。达到或超过：勾上，之后再练只更新最好档，不能取消勾。任何时候都可自练，不限未达标。

## 10. 内容规格

### 10.1 目录

13 单元（家长按单元布置，不按页码）：

- 上册：Starter 英语有趣；1 尝试新事物；2 内心强大；3 职业；4 智能家居；5 电影；6 山水闲暇
- 下册：1 音乐；2 交流；3 伸手帮忙；4 诚实；5 野生动物；6 树

每单元多个短主题。MVP：每单元 4 主题。每主题最多 4 对 A-B（约半分钟，默认开口 2 次）。做完回放再换下一个。

B 句要有态度（选、笑、拒绝），不默认 Yes, I am.

### 10.2 内容卡（一对一行）

| 列 | 用途 |
| --- | --- |
| 学期 | 七年级上 / 下 |
| 单元 | 如 U1 |
| 主题 | 如 社团招新 |
| 序号 | 1–4 |
| A | 说伴先说 |
| B | 学生要说 |
| 关键词 | 判定用，不能丢的意思 |
| 截1 | 教「跟两截」前半 |
| 截2 | 后半 |
| 音频 | 可空；下一版对应 R2 文件 |

产品填表导入，家长只勾主题。从课文自动拆卡是更后面的事，第一版不做。

表三页：说明、对话、单元目录。Unit 1 四主题 16 行已录入。加单元 = 对话页往下加行并改目录状态。

### 10.3 MVP 已写死的 Unit 1 主题

尝试新事物，弧线「不敢 → 试一下 → 还行」：

1. 社团招新
2. 食堂新菜
3. 篮球
4. 英语角

## 11. 语音

### 11.1 原则

正式老师声必须是固定的一把英文女声，不能靠各手机系统朗读（会换声）。识别要吃得了上海初一口音。只判内容，不打发音分。

大陆家里不直连 OpenAI。密钥永不进网页。

### 11.2 MVP 运行时

| | 实现 |
| --- | --- |
| 出声 | Cloudflare Worker `POST https://tts.a1b2.cc` → 阿里云百炼 CosyVoice `cosyvoice-v3-flash` + `loongluna_v3`（英式女，约 35–40 岁），`language_hints: ["en"]`。语速 `TTS_RATE = 1`，合成音量 `TTS_VOLUME = 50`。页面播放音量 `volume: 1`。失败才退回浏览器英文朗读。 |
| 听写 | 同一 Worker `POST https://tts.a1b2.cc/asr` → `qwen3-asr-flash`，`language: en`。无麦或失败时打字框。 |
| 预拉 | 进主题预拉本主题 A/B/截1/截2，内存 + IndexedDB（键：文本+语速+音量）。点开始未齐则进度条。 |
| 播放 | 所有云端朗读走同一 AudioContext（带压限），避免麦克风之后「听我的 / 接着演」被系统抬音。点「开始」时解锁播放。 |
| 地址 | 写死，布置页无 URL 输入框。 |

不用 CosyVoice v3.5（无系统音色）。Cloudflare Aura 仅备选，因大陆访问与结算，MVP 不换。

### 11.3 下一版（已锁定）

1. 内容表定稿。
2. 脚本按行调用 CosyVoice，生成 mp3，按 `单元-主题-序号-角色` 命名，上传 R2。体量约 13×4×4×4 ≈ 800 条、十几二十 MB。
3. 运行时：播放只取 R2（或随 Pages 发布的静态文件）；识别仍走 Worker `/asr`。
4. 网页不再为对话句请求 TTS。IndexedDB 预拉降为缺文件时的补丁，可去掉开场进度条。

## 12. 接口与安全（MVP）

Worker 与页面分离。页面 Origin：`https://a.a1b2.cc`。

| 规则 | 说明 |
| --- | --- |
| 门禁 | 请求头 `X-Shuoban-Key` 必须等于 Worker 加密变量 `SHUOBAN_GATE`。未设该变量则 503。钥匙仍在页面源码里，只能挡扫街，挡不住真下决心刷的人。 |
| 来源 | 只认 `Origin === https://a.a1b2.cc`。不校验 Referer 路径（手机跨域会裁掉 `/shuoban`）。CORS 不是 `*`。localhost 调线上 Worker 会失败。 |
| 限流 | 每 IP 每分钟 40 次。TTS 正文超过 400 字、ASR 超过 2MB 拒绝。 |
| 密钥 | `DASHSCOPE_API_KEY`、`SHUOBAN_GATE` 仅 Worker 加密变量。 |
| 建议 | 百炼「用完即停」+ 消费预警；Cloudflare 可再给该域名加 Rate limiting。 |

## 13. 界面与设备

- 手机（视口宽度 &lt; 600px）：整宽撑满，不用宽高比卡宽度（避免 Safari 工具栏把可视高度变矮后左右灰边）。
- 电脑：高度铺满窗口；宽度最多 16:10（`--frame-h: 16`、`--frame-w: 10`），即 `min(窗口宽, 高度 × 10/16)`。不写死像素。窗口拉成竖条时按手机规则撑满。
- 所有页面同一 `#app`。
- 须 https 或本机静态服务才能用麦克风。不要直接双击 html。
- 静态资源用 `?v=` 破 Pages 缓存。

## 14. 非功能与交付

- 技术：TypeScript/React 思路的静态单页（现行实现为浏览器里的 React + htm，无构建步骤）。Pages 构建命令留空，目录即成品。
- 代码本机路径：`~/gl/github/rexapi/shuoban`。改完由用户同步到 https://a.a1b2.cc/shuoban 后硬刷新。Worker 改 `worker.js` 后须在 Cloudflare 再 Deploy。
- 私有家用，不为商店审核、不为公开流量设计。
- 无 Cursor Pro 时不依赖 Origin 云端 Agent；代码可放私有 Git。
- 交付暂定轻量 PWA：`manifest` + 图标 + 全屏。分发仍发 https://a.a1b2.cc/shuoban ，家长用系统浏览器打开，愿意再加到主屏幕。Android Chrome 可安装；iPhone 为分享 → 加到主屏幕。微信内不能安装，须「用浏览器打开」。
- 不做安装广告。不做靠 Service Worker 的离线包（ASR/TTS 必须在线）。

## 15. 明确不做（本阶段）

- 登录、多孩子账号、云端同步进度
- 发音打分、语法讲解、百分制
- 家长在 App 里手写台词
-  verbatim 课文
- 应用商店包、原生 APK、微信小程序
- 运行时直连 OpenAI
- MVP 里做完全年 13 单元内容
- MVP 里从课文自动拆卡
- 下一版之前：R2 预生成替换运行时 TTS
- 保存学生开口录音；家长审音回放
